# Release Notes – BeBlog Maker Tools 0.2.0 / Build 005

## Android Foundation

Build 005 eröffnet mit Android die zweite Zielplattform von BeBlog Maker Tools.

### Neu

- responsive mobile App-Shell
- ausfahrbare Werkzeugnavigation für Smartphone und Tablet
- touchfreundliche Eingaben und Bedienelemente
- Android-Paketkennung `de.beblog.makertools`
- Tauri-Android-Einstiegspunkt
- GitHub-Actions-Workflow zur APK-Erzeugung
- installierbares Debug-APK als GitHub-Actions-Artefakt

### Unverändert

Alle neun Rechner aus Build 004 bleiben fachlich unverändert.

### Version

Der Plattformschritt rechtfertigt den Wechsel von 0.1.x auf **0.2.0**.
