# Release Notes – Build 004

Build 004 erweitert BeBlog Maker Tools um **Workshop Essentials**.

Neu sind ein schneller Schrauben-/Schlüsselweiten-Finder, ein Gewinde-/Bohrungs-Nachschlagewerk und ein Lochkreisrechner mit X/Y-Koordinaten.

Die App bleibt bei ihrem Grundsatz: kleine technische Fragen direkt beantworten, ohne die Oberfläche zu einem vollständigen Konstruktions- oder Normensystem auszubauen.
