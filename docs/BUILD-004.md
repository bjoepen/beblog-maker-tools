# Build 004 – Workshop Essentials

**Produktversion:** 0.1.2  
**Build:** 004  
**Branch:** `build/004-workshop-essentials`

## Ziel

Build 004 beseitigt typische kleine Nachschlageunterbrechungen in der Werkstatt.

## Neue Werkzeuge

### Schrauben & Schlüsselweiten

- metrische Größen M3 bis M16
- Sechskantkopf ISO 4014/4017
- Zylinderkopf mit Innensechskant ISO 4762
- Regelgewindesteigung
- Kernloch
- normale Durchgangsbohrung
- klarer Hinweis auf ältere DIN-Schlüsselweiten

### Gewinde & Bohrungen

- Kernloch für metrische Regelgewinde
- Durchgangsbohrung fein / normal / grob
- Regelgewindesteigung

### Lochkreis

- Teilkreisdurchmesser
- Bohrungsanzahl
- Startwinkel
- Mittelpunkt X/Y
- Radius und Winkelabstand
- Tabelle aller X/Y-Koordinaten

## Nicht Bestandteil

- Feingewinde
- zöllige UNC/UNF-Gewinde
- Torx-Tabellen
- Anzugsdrehmomente
- Festigkeitsklassenberechnung
- CAD-/DXF-Export

Diese Punkte können später separat bewertet werden.
