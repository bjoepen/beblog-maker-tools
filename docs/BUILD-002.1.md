# Build 002.1 – Official Blog Logo Alignment

Build 002.1 aktualisiert die Markenmarke von BeBlog Maker Tools.

Ziel dieses Zwischenstands ist keine funktionale Erweiterung, sondern die visuelle Angleichung an den realen Blogauftritt unter `https://blog.beblog.de/`.

## Änderungen

- offizielle SVG aus dem Blog in das Repository übernommen
- bisheriges leicht abweichendes Zeichen ersetzt
- BrandMark-Komponente direkt auf das SVG umgestellt

## Technische Umsetzung

- neues Asset: `src/assets/beblog-mark.svg`
- aktualisierte Komponente: `src/components/BrandMark.svelte`
- ergänzte CSS-Regel für skalierte SVG-Darstellung

## Ergebnis

Das Sidebar-Logo entspricht jetzt dem tatsächlichen Blog-Zeichen 1:1.
